# Text Cleaning Project

This project cleans a small text dataset using Python.

## Features
- Lowercases text
- Removes punctuation
- Removes stopwords
- Tokenizes text
- Saves cleaned data to CSV

## Libraries Used
- pandas
- nltk

## How to Run

Install libraries:

```bash
pip install pandas nltk
```

Run the script:

```bash
python clean_text_dataset.py
```

## Output

The project creates:

cleaned_text_dataset.csv
